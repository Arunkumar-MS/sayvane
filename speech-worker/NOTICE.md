# Third-party notices: sayvane-speech

The Sayvane local speech worker (`sayvane-speech`) statically links the
following open-source components. Speech model weights are not bundled with
the worker; they are downloaded or imported separately and are listed here
because the app installs them.

| Component | Version | Use | License |
| --- | --- | --- | --- |
| whisper.cpp (includes the ggml tensor library) | v1.9.5 | Speech recognition engine, statically linked | MIT |
| nlohmann/json | v3.12.0 | JSON parsing for the worker protocol, header only | MIT |
| OpenAI Whisper model weights (GGML conversions hosted at huggingface.co/ggerganov/whisper.cpp) | tiny, base, small, large-v3-turbo, tiny.en | Speech models, installed separately | MIT |
